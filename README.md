# 深度学习与空间智能 - 作业 2：场景目标检测与视频多目标跟踪

本项目是“深度学习与空间智能”课程的第二次作业，主要任务是利用 YOLOv8 模型对交通场景中的车辆进行检测、跟踪以及越线计数。项目涵盖了从模型训练、多目标跟踪到复杂场景分析（遮挡与 ID 跳变）及逻辑判断（越线计数）的完整流程。

**记录时间**：2026年5月14日

---

## 项目结构

本项目主要包含以下核心模块：

1.  **模型训练 (Task 1)**：使用 Road Vehicle Images Dataset 微调 YOLOv8 模型。
2.  **视频跟踪 (Task 2)**：对测试视频进行逐帧推理，实现多目标跟踪与 ID 分配。
3.  **遮挡分析 (Task 3)**：分析遮挡场景下的 ID 跳变与维持机制。
4.  **越线计数 (Task 4)**：基于虚拟线与跟踪 ID 实现物体计数。

### 2. 任务执行流程

#### 模型训练
加载预训练的 YOLOv8n 模型，并使用自定义数据集进行微调。
- **数据集**：Road Vehicle Images Dataset
- **模型**：yolov8n.pt (Nano 版本)
- **关键参数**：
    - `epochs`: 1 (演示用，实际建议 50-100)
    - `imgsz`: 640
    - `batch`: 16
    - `device`: CPU (代码中显式指定为 'cpu')

#### 视频流检测与多目标跟踪
利用训练好的模型对视频进行处理，结合 ByteTrack 算法实现 ID 稳定跟踪。
- **输入**：`test_video_cc.mp4`
- **输出**：`output_tracked.mp4`
- **特性**：
    - 使用 `model.track()` 开启跟踪模式。
    - 置信度阈值 (`conf`) 设定为 **0.359** (基于 F1 曲线分析得出的最优值)。
    - **自定义绘制**：代码中实现了仅显示 ID、不显示类别的可视化逻辑。

#### 遮挡与 ID 跳变分析
*(注：此部分主要为理论分析与结果观察，代码中通过任务 2 的日志和视频进行验证)*
- **现象分析**：在密集交汇或遮挡场景下，观察跟踪算法是否维持了原有 ID。
- **原理**：基于外观特征（Appearance Feature）与运动信息（Motion）的匹配。当遮挡导致特征丢失或匹配失败时，会发生 ID 跳变（ID Switch）。

#### 越线计数
在视频画面中设定一条虚拟垂直线，统计跨越该线的物体数量。
- **逻辑**：
    1. 初始化一个字典 `track_history` 存储每个 ID 上一帧的 X 坐标。
    2. 设定画面中间为虚拟线 (`line_x = width / 2`)。
    3. **判断逻辑**：若某 ID 上一帧位于线左侧 (`prev_cx <= line_x`)，而当前帧位于右侧 (`cx > line_x`)，则计数器 `total_count` 加 1。
- **可视化**：实时在画面上绘制虚拟线并显示当前统计总数。
